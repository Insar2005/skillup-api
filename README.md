# SkillUp v29.5 — компактный ИИ-чат, вложения и голос

**Основа:** ранее работающие v29.4, Telegram HMAC, PostgreSQL, Railway. Обновляем 2 существующих сервиса, не создаём новый. Ни один секрет не должен попадать в Git/архив.

## Что изменено

- Вкладка ИИ — один полноценный экран чата без приветственных карточек, учебных уроков, секции «Предыдущая версия» и технических пояснений. История остаётся на сервере, перенос старых локальных записей доступен через меню «•••» (по подтверждению).
- Внизу чата «+» для JPG/PNG/WebP/PDF, микрофон и текстовое поле. Фотографии и PDF анализирует Claude Sonnet 5.5; голос из Mini App распознаётся OpenAI API. На iOS/Telegram WebView разрешение микрофона зависит от клиента — при отказе можно отправлять голосовые в обычном чате Telegram-бота.
- Вкладка «Финансы» больше не показывает старую кнопку браузерного распознавания речи; ручное добавление доходов/расходов остаётся.
- `ai_receipt_drafts`: извлечённые позиции и категории, исходные фото/PDF на сервере не хранятся. Если сумма строк совпадает с итогом чека и валюта явно прочитана, чек записывается автоматически, с возможностью отмены. Иначе показываем один экран проверки на весь чек. Не складываем сумму строк и итог повторно.
- Понятные текстовые расходы/доходы сохраняются автоматически (в Mini App и боте); бот показывает «Отменить» для своей записи. Например: «Купил iPad за 1000» — использует выбранную основную валюту. ИИ не получает права произвольно менять БД.
- В Профиле можно выбрать валюту по умолчанию (RUB/KGS/USD/EUR/KZT). Каждая операция хранит валюту. Без проверенного курса разные валюты нельзя складывать, поэтому старая рублёвая статистика показывает только RUB, а другие валюты — отдельной строкой и в истории; полноценный единый баланс с курсами — отдельный следующий этап.
- В Telegram-боте фото чеков и PDF обрабатываются тем же Claude Vision; бот также принимает голосовые и текст. Для явно сходящегося чека запись автоматическая, иначе одно подтверждение для всего чека. Можно отменить импорт чека.
- Claude отвечает коротко без Markdown-звёздочек; длинный отчёт по запросу бот отправляет целиком, разбивая на логичные сообщения, а не обрезая в середине предложения.

## Безопасная установка

1. **Резервная копия:** до установки сохраните последний работающий коммит API и фронтенда, а также создайте snapshot/backup PostgreSQL в Railway. **Не стирайте** таблицы и локальные данные.
2. Установите файлы `SkillUp_v29_5_API_CHAT_MEDIA.zip` в **существующий** репозиторий `skillup-api` с заменой файлов (с сохранением ваших неучтённых изменений). Migration `004_ai_media.sql` добавляет таблицу `ai_receipt_drafts` и колонку `users.preferred_currency`, не очищая данные.
3. В `skillup-api → Variables` проверьте `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `PUBLIC_API_BASE_URL`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `CORS_ORIGINS` (ваш HTTPS-домен Mini App). Рекомендуется `ANTHROPIC_MODEL=claude-sonnet-5-5`, `TRANSCRIPTION_MODEL=whisper-1`. **Не присылайте значения токенов.** Не включайте `TELEGRAM_WEBHOOK_AUTO_REGISTER=true` без проверки текущего webhook, если им пользуется другой сервис.
4. Дождитесь Deploy API, проверьте `/` → `0.3.2-chat-media` и `/health` → база connected. Не используйте фронтенд, пока API не обновлён: старый API не имеет новых маршрутов вложений.
5. Установите файлы `SkillUp_v29_5_FRONTEND_CHAT.zip` в GitHub репозиторий **основного** SkillUp. `Dockerfile` уже копирует **и** `skillup-ai.js`, **и** `skillup-cloud.js` внутрь Nginx. После Deploy проверьте, что оба пути отдают JavaScript, а не `index.html`.
6. Полностью закройте Mini App и откройте из Telegram. Сначала в Профиле установите основную валюту (например KGS).

## Ручная проверка

1. Отправьте «Купил iPad за 1000» → короткий ответ, запись в PostgreSQL с `currency=KGS` при выбранной валюте KGS. Проверить из Mini App и второго устройства.
2. Отправьте фото чека, на котором видны строки, итог и KGS → если строки сходятся, бот сразу записывает, затем доступна «Отменить». Если фото нечёткое, проверьте черновик, не сохраняйте сомнительную сумму.
3. В Mini App нажмите «+» и отправьте фото или PDF. Убедитесь, что вложение обработано и запись появилась в Финансах после «Обновить с сервера». Если облако покажет конфликт версий 409, не перезаписывайте данные без проверки резервной копии.
4. Нажмите микрофон в ИИ, продиктуйте фразу, остановите запись. Расшифровка появится в поле ввода для проверки; нажмите «Отправить».
5. Проверьте, что Финансы по-прежнему позволяют вручную добавлять операции, цели и прогресс работают, а в чате нет старых карточек и «Демо».
6. Проверить старую историю с другого устройства; приложение не должно отправлять фото/голос сторонним пользователям. Содержимое фото поступает сервису Anthropic для анализа, голос — OpenAI для распознавания.

## Ограничения этого этапа

- Это **кодовое обновление, не проверенное на вашем реальном Railway/iPhone**. Для некоторых Telegram iOS WebView запись микрофона через MediaRecorder может быть недоступна; тогда используйте обычный голосовой чат бота. Ключи API остаются только на сервере.
- Обработка валютного обмена, курсов за дату операции, объединённого баланса в основной валюте пока не реализована. **Сом нельзя суммировать с рублём без курса.**
- Фоновые напоминания через бота запланированы отдельным этапом: их нет в этом пакете. Не показывать фиктивные уведомления как настоящие.
- Claude может ошибаться при чтении чека. Несмотря на защиту от повторного учёта итога и отдельный контроль валюты, после первых реальных тестов проверьте суммы. Для полной продакшн-готовности нужны ограничения затрат на уровне пользователя/плана, проверка медиа на вредоносное содержимое, тесты миграции и нагрузочные тесты.
