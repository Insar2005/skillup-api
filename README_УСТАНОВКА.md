# SkillUp v29.8 — экспериментальный Agent Bridge (точечный патч)

**Это НЕ новый сервер и НЕ полный релиз «всемогущего агента».** Патч основан на локальной реконструкции v29.7. В GitHub могли появиться другие изменения: обязательно сначала сверить текущие исходники. Не загружать ZIP как замену папки `src`.

## Задача

- Чёткие короткие расходы (включая `-576 такси` и `−576 такси`) выполняются существующим быстрым серверным маршрутом.
- Можно опционально включить GPT через `AI_PROVIDER=openai`, сохраняя Claude по умолчанию.
- GPT Responses API получает **реальные** серверные инструменты: `list_goals`, `get_progress_report`, `get_finance_summary`, `record_finance`. Запросы идут через проверенную сервером личность пользователя, модель не может подменить Telegram ID.
- При записи суммы/валюты сервер сравнивает аргументы GPT с исходным сообщением. Подтверждение об успехе возвращается только после коммита PostgreSQL. Повтор по тому же ключу не создаёт вторую операцию.
- В Telegram при записи через GPT предлагается «Отменить»; Mini App получает `financeChanged` для обновления облака.
- Текущие независимые инструменты `agent-actions`, `development-actions` остаются как есть. Никаких прямых SQL-команд и массовых удалений от модели.

## Сначала

1. Сохранить резервную копию PostgreSQL и ID работающего коммита API.
2. Убедиться, что Working Copy **не находится в незавершённом merge** и файлы `src/server.js`, `src/ai-media.js`, `src/bot-finance.js`, `src/agent-dispatch.js`, `src/agent-actions.js`, `src/development-actions.js` и старые `sql/001`–`007` существуют.
3. Проверить различия с текущим GitHub `main`. Применить изменения **выборочно**: добавить `src/openai-agent.js`, обновить `src/ai-finance.js`, `src/ai.js`, `src/bot.js` и `src/ai-routes.js`. Последние четыре могут содержать более свежие изменения: тогда перенести отдельные функции вручную, а не заменять файлы.
4. Никаких изменений SQL, `server.js`, Dockerfile и frontend этот патч не содержит.

## Переменные Railway, сервис skillup-api

- По умолчанию ничего менять не нужно: Claude остаётся основным движком.
- Для эксперимента: `AI_PROVIDER=openai`.
- Уже существующий `OPENAI_API_KEY` нужен для GPT и Whisper. Не публиковать его в Git.
- `OPENAI_AGENT_MODEL=gpt-5.4-mini` — указать реальный идентификатор модели, доступный **твоему API-аккаунту** (при ошибке model_not_found сверить с документацией/доступом).
- Чтобы вернуть Claude: `AI_PROVIDER=anthropic` или удалить `AI_PROVIDER` и перезапустить API.
- Вызовы Claude для обработки изображений остаются прежними. Этот патч не переключает фото/чеки на GPT.

## Тест в Telegram (тестовый аккаунт)

1. `−576 такси` → `Записал −576 [основная валюта] · Транспорт`, есть отмена. Сумму проверить в Mini App и на другом устройстве.
2. `Сколько я потратил на такси 576 сом?` → не должна появиться операция.
3. `80 сомов за кофе` → расход, «Еда вне дома».
4. `Покажи мои последние расходы` → GPT должен читать PostgreSQL через `get_finance_summary`, а не отрицать наличие записей.
5. Проверить «Измени сумму последнего расхода на 850» (старый Agent Actions), затем отмену.
6. Проверить голос, изображение чека, цели и перезапуск Mini App. Никакие тестовые операции в настоящей базе автоматически не создавать.

## Ограничения

Это **первый контролируемый tool-calling слой**. В GPT-режиме модель может самостоятельно вызывать только 4 перечисленных инструмента. Изменение цели, редактирование даты, защищённое удаление и откат пока остаются у существующих серверных обработчиков. Для действительно единого агента надо отдельно расширить реестр с проверенными схемами для каждого действия, защитой ревизий и безопасными тестами. Патч не был запущен на реальном Railway с ключами, клиентами или реальной базой.
